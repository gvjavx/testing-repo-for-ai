# Perencanaan Landing Page

## 1. Product Owner (Fokus)
Membuat landing page sederhana yang berfungsi sebagai pintu masuk untuk produk/layanan (dummy). Fokus pada minimal viable product:
- Judul utama & sub-judul.
- Call to Action (CTA) utama.
- Informasi singkat tentang layanan.

## 2. Project Manager (Jadwal/Alur)
1. **Fase Desain**: Membuat wireframe visual dasar (HTML/CSS).
2. **Fase Coding**: Implementasi struktur HTML dan styling (menggunakan Tailwind yang sudah terinstall di `node_modules`).
3. **Fase QA**: Validasi responsivitas tampilan di mobile dan desktop.

## 3. System Analyst (Teknis)
- Menggunakan `index.html` yang sudah ada sebagai file utama.
- Memanfaatkan CSS dari Tailwind (atau style custom jika lebih cepat).
- Tidak memerlukan backend, murni static file.
